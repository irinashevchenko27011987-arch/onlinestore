интернет-магазин
Это интернет-магазин мебели, созданный для того, чтобы помочь клиентам подобрать стильную и функциональную мебель для дома. На сайте представлен каталог товаров с различными категориями (например, мебель для гостиной, спальни, кухни), удобная система поиска и корзина для оформления заказов. Главная цель проекта — предоставить пользователям простой и приятный опыт покупки мебели онлайн, с акцентом на современный дизайн и качество. Слоган сайта: «Всё, чего заслуживает ваш дом».
HTML5 — для структурирования страниц (главная страница, каталог, корзина).CSS3 — для стилизации сайта: оформление заголовков, блоков с товарами, цветовой схемы, шрифтов, адаптивного дизайна.Статические изображения и медиафайлы
